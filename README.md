# 诗词格律校验器

> **以知识库为尺，量诗词之律。**
> 本项目**不含 AI**，也不生成任何内容。它的职责只有一个：
> 把你手里的诗词，逐字对照韵书与格律，指出哪里不合、为什么不合、怎么改。

---

## 这个项目解决什么问题

AI 写诗很快，但**常常出律**：

```
❌ 写「东」韵的诗，却混进了「冬」韵的字（普通话同音，平水韵不同部）
❌ 「一、白、雪、月」当成平声用（这些是入声字，全是仄声）
❌ 押韵句末尾三字全平（三平调，大忌）
❌ 律诗的颔联、颈联忘了对仗
❌ 填词时字数对不上词谱，或该换韵的地方没换
```

人眼校对这些很费神，因为**平水韵和普通话差别巨大**，光靠记忆容易出错。

本项目就是那把尺子。

## 工作流

```
          ┌──────────────┐
          │  1. 人下指令  │  「写一首五律，押十一尤韵，咏秋」
          └───────┬──────┘
                  ▼
          ┌──────────────┐
          │  2. AI 生成   │   ← 这一步在 ChatGPT / Claude 等外部工具完成
          └───────┬──────┘      本项目不参与
                  ▼
          ┌──────────────┐
          │  3. 粘贴进本  │  python main.py -t "……"
          │     项目校验  │
          └───────┬──────┘
                  ▼
          ┌──────────────┐
          │ 4. 输出报告   │  出律位置、韵部归属、对仗分析
          └───────┬──────┘
                  ▼
          ┌──────────────┐
          │ 5. 人修改     │  → 回到第 3 步，直到「合律」
          │  （或让 AI 改）│
          └──────────────┘
```

> 本项目刻意**不做第 2 步**。理由见文末「为什么不做 AI」。

## 能校验什么

### 近体诗

| 项目 | 说明 |
| --- | --- |
| **体例** | 五/七言，绝句 / 律诗 / 排律，自动识别 |
| **格式** | 四种基本句式 × 首句入韵与否 = 16 种诗谱，全部推导得出 |
| **平仄** | 逐字比对；「一三五不论」从宽处理 |
| **拗救** | 孤平、孤平拗救、三平调、三仄尾、特拗句、半拗 |
| **押韵** | 韵部归属、韵脚一致性、首句借邻韵、重韵、仄韵变体提示 |
| **对仗** | 颔联 / 颈联按节奏点切分，词类对照，平仄相对，重字检查 |

### 词

| 项目 | 说明 |
| --- | --- |
| **认牌** | 从标题识别词牌，支持别名（望江南→忆江南、乌夜啼→相见欢） |
| **字数** | 总字数、逐句字数与词谱核对 |
| **句读** | 按词谱长度自动切句，不依赖标点 |
| **平仄** | 逐字比对词谱（`中` 处不论） |
| **押韵** | 按韵标记分组（平韵 / 仄韵 / 叶韵 / 叠韵 / 换韵），查《词林正韵》 |
| **句读诊断** | 总字数对但逐句字数不对时，自动判断「只是逗的位置错」还是「要改字」，并给出按谱重断的断句 |
| **句读骨架** | 报告顶部列出各句字数（如 `5·5·6·5·6·6·5·5·5`），填词时照着断句 |
| **对仗** | 给出该词牌的对仗位置提示 |

### 改字建议（韵脚）

韵脚出韵或重韵时，程序会从主韵部里筛出**平仄相符**的候选字，按诗词常用度排序：

```
● [建议] 押韵换字建议：「波」不在主韵《词林正韵》第一部（该韵位需 平声）。
  可从主韵部中选平声字替换，例如：东、铜、桐、中、虫、终、弓、宫、熊、穷、
  风、枫、功、红、虹、翁、蓬、冬、钟、龙、松、胸、重、从……
  （仅按韵部与平仄筛出，语义是否相合请自行斟酌）
```

> **只对韵脚给建议。** 非韵脚的出律字，程序只说「此处需仄声」——
> 换哪个字取决于句意与语感，纯规则给的候选必然词不达意，不如不说。

| 韵书 | 用途 | 依赖 |

## 设计原则

### 数据与逻辑分离

**代码里没有任何一个字的平仄知识。** 想知道「月」是平是仄？只能查韵书。

```python
KB.tones("月")        # {'仄'}      ← 来自 知识库/韵书/平水韵.json
KB.tones("看")        # {'平', '仄'} ← 多音字
KB.tones("东")        # {'平'}
```

**改数据即改标准，无需改代码。**

### 只存必要数据，其余推导

- 平水韵存 106 韵的**字表**；
- 词林正韵只存**映射**（哪几个平水韵部合成一部），不重复抄字表；
- 近体诗格律只存**四种基本句式与对粘规则**，16 种诗谱由程序推导。

好处：不会出现「同一份数据抄了两遍、改一处忘另一处」的错误。

### 宁可留白，不可妄断

程序**不能**判断意境、合掌、流水对。这些一律标注「仅供参考」，交由人判断。

定位是**辅助工具，不是评判者**。

## 怎么扩充知识库

### 遇到「韵书未收录」

说明该字不在数据中。程序会明确列出，不会瞎猜。

```bash
$ python main.py -t "我的诗……"
  ● [提示] 韵书未收录：以下字不在平水韵数据中，未参与平仄判定：某。
```

**补录步骤：**

1. 查证该字在平水韵中的归属（推荐《佩文韵府》或中华诗词学会资料）；
2. 打开 `知识库/韵书/平水韵.json`，在**对应韵部的字符串末尾**追加该字：

```json
"一东": "东同铜桐筒童…（原有字）…你的新字"
```

3. 重新运行。词林正韵会自动跟着更新（它是从平水韵推导的）。

### 增补词牌

在 `知识库/词谱/词牌格律.json` 的 `词牌` 对象里按同样的格式加一条即可，无需改代码。
加完运行：

```bash
python main.py --verify-kb
```

自检会核对「谱长是否等于标称字数」「句数是否一致」。

### 改完记得自检

```bash
python main.py --verify-kb
```

| 限制 | 说明 |

| 平水韵收字约 3400 | 覆盖诗词常用字；生僻字会提示「未收录」，可自行补录 |

## 常见问题

**Q：为什么「东」和「冬」不能通押？**
A：在**平水韵**中这是两个韵部。普通话里都是 `-ong`，所以听起来同音。
这是近体诗最常踩的坑之一。改用「中华新韵」标准则可以通押。

**Q：为什么「一、白、月、雪」算仄声？**
A：它们是**入声字**。入声在平水韵中属仄声。现代普通话已无入声，
这些字被派入阴平、阳平、上声、去声，所以听起来像平声或上声，实际是仄声。

**Q：一定要打标点吗？**
A：不用。程序会按 5 字或 7 字自动分句。填词则按词谱长度切句。

**Q：填词怎么让程序知道词牌？**
A：写在标题里，三种写法都认：

```
《浣溪沙》
浣溪沙·一曲新词酒一杯
词牌：浣溪沙
```

**Q：能一次校验多首吗？**
A：目前一次一首。批量处理可以用库接口循环调用 `analyze()`。

## 为什么不做 AI

这是**刻意的设计**，不是能力欠缺。

1. **校验必须是确定的。** 平仄、押韵、对仗都是可判定的问题，答案唯一。
   引入生成模型只会让「对不对」变成「像不像」，反而降低可信度。

2. **生成与校验分离，才能互相验证。** 让 AI 写、让规则查，
   两套系统各司其职。若 AI 既写又判，它可能会为自己的错误背书。

3. **知识库是资产。** 韵书、词谱是千年来沉淀的硬知识，可以不断积累、复核、
   传承。这部分不会因模型换代而失效。

4. **人可以学到东西。** 报告会告诉你「这里为什么不合律」，
   而不只是「重写一遍」。用久了，格律感自然就长出来了。

> 一句话：**AI 负责才气，本项目负责规矩。**
