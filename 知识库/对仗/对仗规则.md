# 对仗规则

> 律诗的颔联（3、4 句）与颈联（5、6 句）必须对仗。这是「格律」之外的第二道硬指标。
> 程序读取同目录下的 `词类分类.json` 作辅助判定。

## 一、对仗的三条基本要求

| 要求 | 内容 |
| --- | --- |
| **字数相等** | 出句与对句字数相同（近体诗中天然满足）。 |
| **平仄相对** | 出句第二字与对句第二字平仄相反（这与「对」的规则一致）。 |
| **词性相当** | 相同位置的词，词性相同、门类相类。 |

第三条是对仗的灵魂，也是最难用程序判定的部分。

## 二、工对与宽对

### 工对

同门类词相对，称工对：

```
两个黄鹂鸣翠柳，一行白鹭上青天。
↑ 数目      ↑ 鸟兽           ↑ 数目  ↑ 鸟兽
       ↑ 颜色                ↑ 颜色
```

- 「两个」对「一行」——数目对数目
- 「黄鹂」对「白鹭」——鸟兽对鸟兽，且颜色相对
- 「翠柳」对「青天」——草木对天文，且颜色相对

### 宽对

门类不同但词性相当，为宽对，律诗中大量存在：

```
无边落木萧萧下，不尽长江滚滚来。
```

「落木」（草木）对「长江」（地理），同属名词，属宽对，仍为好联。

### 判定尺度

| 情形 | 判定 |
| --- | --- |
| 相同位置门类完全一致 | 工对 |
| 名词对名词、动词对动词，但门类不同 | 宽对 |
| 词性不同（如名词对动词） | **失对** |
| 位置结构不对齐 | **失对** |

> **邻类可以放宽**：天文↔时令、地理↔宫室、器物↔衣饰、草木↔鸟兽，
> 古称「邻对」，介于工对与宽对之间，不必苛求。

## 三、对仗的避忌

### 1. 忌合掌

出句与对句意思重复，叫「合掌」，是对仗的大忌。

```
❌ 独有英雄驱虎豹，更无豪杰怕熊罴。
   「英雄」与「豪杰」同义，「虎豹」与「熊罴」同义 —— 上下句说同一件事。
```

### 2. 忌重字

除特殊修辞（如叠字、顶真）外，出句与对句不得使用相同的字。

```
❌ 春蚕到死丝方尽，蜡炬成灰泪始干。
   ── 此例实际无重字，属佳对；若「春蚕」对「春柳」，则「春」字重复，为病。
```

### 3. 忌结构不称

```
❌ 风急天高猿啸哀，渚清沙白鸟飞回。
   这两句实为工对（杜甫《登高》首联），说明结构对齐才是关键：
   风急/渚清，天高/沙白，猿啸哀/鸟飞回。
```

### 4. 忌「一三五」不对应

对仗讲究节奏点对齐。若出句是 `2-2-1-2`，对句也应如此。

## 四、对仗的类型

| 类型 | 说明 | 例 |
| --- | --- | --- |
| 正对 | 上下句意平行 | 明月松间照，清泉石上流 |
| 反对 | 上下句意相反 | 年年岁岁花相似，岁岁年年人不同 |
| 流水对 | 上下句意连贯，一句读不完 | 即从巴峡穿巫峡，便下襄阳向洛阳 |
| 借对 | 借音或借义成对 | 沧海月明珠有泪，蓝田日暖玉生烟（借「沧」为「苍」色） |
| 扇面对 | 隔句相对 | 用于词、赋，律诗中罕见 |
| 当句对 | 句中自对 | 风急天高，渚清沙白 |

> **流水对**最难，也最见功力。它上下句不是并列，而是顺承——
> 对仗的形式下藏着连贯的语意。

## 五、程序如何判定

程序做三件事，逐层递进：

1. **位置对齐分析**：把出句、对句按节奏点切分（五言 `2/2/1`，七言 `2/2/2/1`），逐位对照。
2. **平仄相对检查**：第二字（及偶数位）平仄是否相反。
3. **门类对照**：查 `词类分类.json`，标出每位属于哪个门类，并判断：
   - 全部同位同门类 → **工对**
   - 全部同位同词性、部分同门类 → **宽对**
   - 存在名词对动词等词性错位 → **疑似失对**

### 程序的能力边界

| 能自动判定 | 必须人工判断 |
| --- | --- |
| 平仄是否相对 | 是否合掌 |
| 有明显词性错位 | 语意是否重复、是否流水对 |
| 门类是否相类（依据词表） | 借对、当句对等高级手法 |
| 是否有重字 | 意境是否高远 |

> 因此程序的对仗结论统一标注为「**参考**」，最终仍以人工判断为准。
> 本项目的定位是「辅助」，不是「评判」。

## 六、词中的对仗

词中对仗较诗自由，且**是否对仗取决于具体词牌**：

| 词牌 | 对仗位置 |
| --- | --- |
| 浣溪沙 | 下片前两句（4、5 句）多用对仗 |
| 鹧鸪天 | 上片 3、4 句，下片 1、2 句 |
| 满江红 | 上片 4、5 句，下片 4、5 句 |
| 水调歌头 | 上片 3、4 句，下片 6、7 句 |
| 忆江南 | 中间两句（3、4 句）对仗 |
| 西江月 | 上下片前两句各用对仗 |
| 沁园春 | 上片 2、3 句，下片 3、4 句 |

词的对仗**不忌重字**，也不要求平仄相对，比诗宽松得多。

具体请见 `../词谱/词牌说明.md`。
