# 知识库

这里是整个项目的**唯一权威数据源**。程序不含任何硬编码的韵字、词谱，
所有判定都以本目录的内容为准。**改数据即改标准，无需改代码。**

## 目录结构

```
知识库/
├── README.md              ← 本文件
├── 韵书/                   「审音」——一个字是平是仄、属于哪个韵部
│   ├── 平水韵.json          近体诗用（106 韵）
│   ├── 词林正韵.json        填词用（19 部，由平水韵归并）
│   ├── 中华新韵.json        普通话用（14 韵）
│   └── README.md
├── 格律/                   「定式」——一句诗应该长什么样
│   ├── 近体诗格律.json       四种基本句式 + 对粘规则（程序据此推导诗谱）
│   ├── 近体诗格律.md         理论文档（给人读）
│   └── 拗救与特殊句式.md      孤平、三平调、特拗、半拗
├── 词谱/                   「按谱填词」——每个词牌的定式
│   ├── 词牌格律.json         30 个常用词牌的完整格律
│   └── 词牌说明.md           词的结构、押韵、对仗规则
└── 对仗/                   「词性相类」——对仗是否工整
    ├── 词类分类.json         21 个门类的常用字表
    └── 对仗规则.md           工对、宽对、合掌、流水对
```

## 数据流向

```
              知识库/韵书/*.json
                     │
                     ▼
    ┌────────────────────────────────┐
    │  字 → [(韵部, 平仄), …]         │   反向索引
    └────────────────────────────────┘
                     │
   知识库/格律/*.json │        知识库/词谱/*.json
         │           │              │
         ▼           ▼              ▼
   推导出诗谱     判平仄        判押韵      查词牌
         └───────────┴──────────────┴──────────┘
                     ▼
              校验报告（出律／合律）
```

## 设计原则

### 1. 数据与逻辑分离

代码里**不出现任何一个字**的平仄判断。想知道「月」是平是仄？只能查韵书。

这样做的理由：韵书的修订是常事（尤其是新韵），而格律规则千年来几乎不变。
把两者分开，改动成本最低。

### 2. 只存必要数据，其余推导

- `平水韵.json` 存 106 韵的**字表**；
- `词林正韵.json` 只存**映射**（哪几个平水韵部合成一部），不重复抄字表；
- `近体诗格律.json` 只存**四种基本句式与对粘规则**，16 种诗谱由程序推导。

好处：不会出现「同一份数据抄了两遍、改了一处忘了另一处」的错误。

### 3. 只读知识库

程序**永不写回**知识库。想改标准，请直接编辑 JSON。

## 数据完备度

| 数据 | 覆盖度 | 说明 |
| --- | --- | --- |
| 平水韵 | 约 3500 字 / 106 韵 | 覆盖诗词常用字；生僻字可能未收，程序会提示「韵书未收录」 |
| 词林正韵 | 19 部全 | 八处半韵已做字级拆分 |
| 中华新韵 | 14 韵全 | 需安装 `pypinyin` |
| 近体诗格律 | 完整 | 四种句式 + 对粘 + 拗救全套规则 |
| 词牌格律 | 31 个 | 覆盖最常用词牌 |
| 对仗词类 | 20 门类 | 启发式，仅供参考 |

> **遇到「韵书未收录」怎么办？**
> 说明该字不在本项目数据中。请：
> 1. 查证该字在平水韵中的归属；
> 2. 打开 `韵书/平水韵.json`，在对应韵部字符串末尾追加该字；
> 3. 重新运行即可。

## 增补数据的规范

1. **字串以空格分隔**，可读性优先，不必追求紧凑。
2. **不要删除已有字**，只在末尾追加；如需纠正，请连同出处一并说明。
3. **多音字允许重复出现在多个韵部**，这是正确行为，不是数据错误。
4. 修改后运行自检：

```bash
python main.py --verify-kb
```

## 权威性声明

本项目的数据整理自下列公开典籍，力求准确，但**不保证零误差**：

- 《佩文韵府》《诗韵合璧》—— 平水韵
- 戈载《词林正韵》—— 词韵
- 中华诗词学会《中华新韵（十四韵）》—— 新韵
- 《钦定词谱》、龙榆生《唐宋词格律》—— 词牌
- 王力《汉语诗律学》、启功《诗文声律论稿》—— 格律理论

**正式场合请以纸质韵书为准。** 本项目定位为**辅助工具**，不代替人的判断。
