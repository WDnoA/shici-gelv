# 词牌说明

> 本文件是给人读的说明；程序实际读取同目录下的 `词牌格律.json`。

## 一、词和近体诗的根本区别

| | 近体诗 | 词 |
| --- | --- | --- |
| 句式 | 五言或七言，整齐 | **长短句**，参差不齐 |
| 篇制 | 4 / 8 / 12… 句 | **由词牌决定** |
| 押韵 | 平水韵，一韵到底 | **词林正韵**，可平仄换韵 |
| 平仄 | 四种句式组合 | **由词牌决定**，每字有定 |
| 对仗 | 律诗颔、颈联必对 | 视词牌而定，且不忌重字 |
| 标题 | 题目 | **词牌 + 题目**，如《水调歌头·明月几时有》 |

词的关键在于：**每个词牌都有固定的「谱」**——多少句、每句多少字、每个字平仄、
哪里押韵，全都写死。填词就是「按谱填字」。

## 二、词的结构术语

| 术语 | 含义 |
| --- | --- |
| **单调** | 不分段，如《忆江南》《如梦令》 |
| **双调** | 分上下两片（阕），绝大多数词牌属此 |
| **三叠、四叠** | 分三段、四段，如《兰陵王》《莺啼序》 |
| **上片（上阕）** | 前半 |
| **下片（下阕）** | 后半 |
| **过片** | 下片的第一句，最见笔力处 |
| **换头** | 下片首句与上片首句句式不同 |
| **领字** | 一、二字领起下文，多用作去声，如「望」「看」「惜」「念」「对」 |
| **韵脚** | 押韵的字 |
| **叶韵** | 与前面的韵脚同部而平仄不同 |

## 四、词的押韵规则细说

### 1. 用《词林正韵》

词韵比诗韵宽。例如：

- **平水韵**：「东」「冬」是两个韵部，不可通押；
- **词林正韵**：同属第一部，可以通押。

### 2. 平仄分押

多数词牌是「全篇押平韵」或「全篇押仄韵」，不许平仄混押。

```
✅ 浣溪沙（全平韵）：一曲新词酒一杯，去年天气旧亭台，夕阳西下几时回。
                     ↑杯 平    ↑台 平     ↑回 平
```

### 3. 交替换韵

部分词牌要求平仄韵交替，如《菩萨蛮》《虞美人》《减字木兰花》：

```
菩萨蛮  温庭筠
小山重叠金明灭（仄），鬓云欲度香腮雪（仄）。
懒起画蛾眉（平），弄妆梳洗迟（平）。
照花前后镜（仄），花面交相映（仄）。
新帖绣罗襦（平），双双金鹧鸪（平）。
```

> 每两句换一次韵，共四换。**换韵时必须整个韵部换掉**，不能只换一个字。

### 4. 叶韵

有些词牌（如《西江月》）在同一词林正韵部内，平仄韵通押：

```
西江月  辛弃疾
明月别枝惊鹊，清风半夜鸣蝉（平）。稻花香里说丰年（平），听取蛙声一片（仄）。
                                        ↑蝉、年、片 同属词林正韵第七部
```

程序据此判断：`韵标记 4` 表示「同部仄韵」。

### 5. 叠韵

《如梦令》《忆秦娥》有叠句，要求**整句重复**（至少韵脚字重复）：

```
如梦令  李清照
……知否（韵），知否（叠韵）？应是绿肥红瘦（韵）。
```

## 五、常见误区

| 误区 | 正解 |
| --- | --- |
| 词可以随便写长短句 | ❌ 每个词牌字数字数、平仄都是固定的 |
| 词和诗一样一韵到底 | ❌ 很多词牌要换韵 |
| 词的押韵也查平水韵 | ❌ 应当查**词林正韵** |
| 词也忌重字 | ❌ 词**不忌重字**，反而常用叠字、叠句 |
| 字数对了就是对的词 | ❌ 还要看句读、平仄、韵脚位置 |

## 六、程序如何校验一首词

1. 从标题或内容中识别**词牌名**（支持别名）。
2. 按词牌的**句读**切分句子，检查**每句字数**是否吻合。
3. 检查**总字数**是否吻合；不符则尝试匹配同词牌的其他体，并提示。
4. 逐句逐字比对**平仄谱**（`中` 处不论，`平`/`仄` 处严格）。
5. 按 `韵标记` 检查**韵脚位置**与**韵部归属**（用《词林正韵》）。
6. 对标记了 `对仗` 的位置做**对仗参考分析**。

输出示例：

```
【词牌】浣溪沙（别名：浣纱溪、小庭花）
【字数】42 / 42  ✔
【句数】6 / 6     ✔
【平仄】6 句中有 5 句合谱，第 4 句第 3 字出律
【韵脚】杯(第三部·支) 台(第三部·支) 回(第三部·支)
        前(第七部·先) 边(第七部·先) 见(第七部·霰)
        ⚠ 上片与下片韵部不同，浣溪沙应一韵到底
```
