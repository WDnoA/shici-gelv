# 韵书知识库

本目录存放「审音辨韵」所需的全部标准数据。校验程序只读取本目录，不做任何硬编码，
因此增补、修订韵书只需改这里的 JSON，无需改动代码。

## 目录

| 文件 | 名称 | 用途 | 依赖 |
| --- | --- | --- | --- |
| `平水韵.json` | 平水韵（106 韵） | 近体诗（律诗、绝句、排律）押韵与平仄的正统标准 | 无 |
| `词林正韵.json` | 词林正韵（19 部） | 词的押韵标准，由平水韵 106 韵归并而成 | 无 |
| `中华新韵.json` | 中华新韵（14 韵） | 按普通话读音押韵的现代标准 | `pypinyin`（可选） |

## 三套韵书的关系

```
平水韵（106 韵，含入声）
   └─ 归并 ─→ 词林正韵（19 部，入声独立成部）

中华新韵（14 韵，按普通话，无入声）
```

- **写近体诗** → 用平水韵。这是传统正道，也是历代名作的实际用韵。
- **填词** → 用词林正韵。
- **写现代诗 / 新韵诗** → 用中华新韵。

三套标准**不可混用**。同一首诗，用平水韵判定「出韵」，用中华新韵判定「合韵」是常有的事
（例如「东/冬」在平水韵中不同韵，在普通话里都是 `-ong`）。

## 平水韵的结构

```
上平声 15 韵（平）  一东 二冬 三江 四支 五微 六鱼 七虞 八齐 九佳 十灰 十一真 十二文 十三元 十四寒 十五删
下平声 15 韵（平）  一先 二萧 三肴 四豪 五歌 六麻 七阳 八庚 九青 十蒸 十一尤 十二侵 十三覃 十四盐 十五咸
上声   29 韵（仄）  一董 … 二十九豏
去声   30 韵（仄）  一送 … 三十陷
入声   17 韵（仄）  一屋 … 十七洽
                    ────────────────
                    合计 106 韵
```

### 三条必须记住的规则

1. **上平、下平都是「平声」。** 「上」「下」只是卷次编号，与平仄无关。
   初学最容易把「下平声」误当作仄声。
2. **上、去、入都是「仄声」。** 其中**入声**是现代人最难掌握的部分：
   普通话里「一、白、雪、月、石、读」读起来像平声或上声，但在平水韵中全是**仄声**。
3. **一个字可以同时属于多个韵部。** 这是多音字 / 多义字造成的，校验程序会全部列出，
   由使用者按诗意取用。例如：
   - 「看」：上平十四寒（平，kān）／去声十五翰（仄，kàn）
   - 「思」：上平四支（平，sī）／去声四寘（仄，sì）
   - 「过」：下平五歌（平，guō 国名）／去声二十一个（仄，guò）
   - 「望」：下平七阳（平，wáng）／去声二十三漾（仄，wàng）

## 数据格式

### 平水韵

```json
{
  "韵部": {
    "上平声": { "一东": "东同铜桐筒童…", "二冬": "冬农宗钟龙…" },
    "下平声": { "一先": "先前千阡笺天…" },
    "上声":   { "一董": "董懂动孔总笼…" },
    "去声":   { "一送": "送梦凤洞众瓮…" },
    "入声":   { "一屋": "屋木竹目服福…" }
  }
}
```

- 「字」为**空格分隔的字串**，不是数组，便于人工阅读与增补。
- 平仄由所在大类推导：`上平声`/`下平声` → 平；`上声`/`去声`/`入声` → 仄。
- 程序启动时构建反向索引：`字 → [{韵部, 平仄}, …]`。

### 词林正韵

采用**映射**而非重复抄录字表，避免与平水韵不一致：

```json
{
  "部映射": {
    "第一部": { "平": ["上平声一东", "上平声二冬"], "上": [...], "去": [...] }
  },
  "半韵字表": {
    "上平声十灰": { "第三部": "灰恢魁隈回…", "第五部": "开哀埃台苔…" }
  }
}
```

### 中华新韵

只存**韵母 → 韵部**的对应表，字到韵部的转换在运行时由 `pypinyin` 完成。

## 如何增补数据

### 增补平水韵的字

直接在对应韵部的字符串**末尾**追加，字与字之间用中文全角空格或半角空格分隔均可：

```json
"一东": "东同铜桐筒童 … 原有字 新增的字1 新增的字2"
```

> 增补前请确认该字在此韵部中的**平仄**是否正确。建议以《佩文韵府》《诗韵合璧》
> 或中华诗词学会公布的资料为准。

### 新增一套韵书

1. 在本目录新建 `你的韵书.json`；
2. 在 `poetry_checker/knowledge.py` 的 `RHYME_BOOKS` 注册表中加入文件名；
3. 若结构特殊（非「大类 → 韵部 → 字串」），需在加载器中补充解析分支。

### 校验数据完整性

```bash
python main.py --verify-kb
```

该命令会检查：JSON 是否合法、韵部名称是否重复、同一韵部内是否有重字、
是否有字同时落在互相冲突的平仄中（正常多音字除外，会单独列出）。
