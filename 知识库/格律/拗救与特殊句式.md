# 拗救与特殊句式

> 「拗」是不合平仄定式的地方；「救」是在本句或对句的相应位置作平仄补偿。
> 经过「救」的句子视为合律——这是本程序判定时的重要依据。

## 一、总原则

平仄定式只是骨架，「一三五不论，二四六分明」给了创作者相当的自由度。
但自由有边界，越界即为「病」。下面按严重程度排列。

| 名称 | 严重程度 | 是否可救 | 程序默认处理 |
| --- | --- | --- | --- |
| 孤平 | ★★★ 大忌 | 可救 | 报错 |
| 三平调 | ★★★ 大忌 | 不可救 | 报错 |
| 三仄尾 | ★☆☆ 小病 | 不必救 | 警告 |
| 特拗句 | 0 不算病 | — | 直接认可 |
| 半拗 | 0 不算病 | 不必救 | 直接认可 |


## 二、孤平

### 定义

**押韵的句子（平收句）中，除韵脚外，只有一个平声字**，就叫孤平。

> 只有「平收句」会犯孤平；仄收句不论。

### 典型情形

定式「**平平仄仄平**」（五言平起平收）：

```
定式：  平 平 仄 仄 平
第一字作仄：仄 平 仄 仄 平   ← 除韵脚「平」外只有第 2 字一个平声 → 孤平
```

七言定式「**仄仄平平仄仄平**」：

```
定式：    仄 仄 平 平 仄 仄 平
第三字作仄：仄 仄 仄 平 仄 仄 平   ← 除韵脚外只有第 4 字一个平声 → 孤平
```

### 孤平拗救

把**本句的第三字**（五言）／**第五字**（七言）由仄改平：

```
仄 平 仄 仄 平   →   仄 平 平 仄 平
（孤平）              （已救，合律）
```

```
仄 仄 仄 平 仄 仄 平   →   仄 仄 仄 平 平 仄 平
（孤平）                    （已救，合律）
```

程序检测逻辑：若某平收句被判为孤平，则回查该句是否满足「第四字（五言）／
第六字（七言）为平，且第三字（五言）／第五字（七言）为平」，满足则判为「已救」。


## 三、三平调

### 定义

**平收句末尾三字全为平声**，称三平调。这是古体诗的典型特征，近体诗中是大忌。

```
定式：仄 仄 仄 平 平
第三字作平：仄 仄 平 平 平   ← 末尾三字「平平平」→ 三平调
```

七言同理：

```
定式：平 平 仄 仄 仄 平 平
第五字作平：平 平 仄 仄 平 平 平   ← 三平调
```

**三平调不可救**，只能改字。


## 四、三仄尾

### 定义

**仄收句末尾三字全为仄声**。

```
定式：平 平 平 仄 仄
第三字作仄：平 平 仄 仄 仄   ← 末尾三字「仄仄仄」→ 三仄尾
```

七言：

```
定式：仄 仄 平 平 平 仄 仄
第五字作仄：仄 仄 平 平 仄 仄 仄   ← 三仄尾
```

三仄尾比孤平、三平调轻得多，唐诗中不乏其例（尤其「平平仄仄仄」），
但初学仍以避之为上。程序默认给**警告**而不判为出律。


## 五、特拗句（鲤鱼翻波）

这是最需要程序识别的「看似出律实则合律」的情形。

### 五言

定式「**平平平仄仄**」→ 变体「**平平仄平仄**」。

```
定式：平 平 平 仄 仄
变体：平 平 仄 平 仄
      ↑     ↑
      第3字拗（平→仄）
            第4字救（仄→平）
```

即：第四字该仄而用平，第三字该平而用仄，**本句自救**。

### 七言

定式「**仄仄平平平仄仄**」→ 变体「**仄仄平平仄平仄**」。

```
定式：仄 仄 平 平 平 仄 仄
变体：仄 仄 平 平 仄 平 仄
                ↑     ↑
```

### 实例

| 诗句 | 作者 | 说明 |
| --- | --- | --- |
| 凉风**起天末** | 杜甫《天末怀李白》 | 平平仄平仄 |
| 明朝**望乡处** | 王维《杂诗》 | 平仄仄平仄（首字亦不论） |
| 正是**江南好风景** | 杜甫《江南逢李龟年》 | 仄仄平平仄平仄 |
| 庾信**平生最萧瑟** | 杜甫《咏怀古迹》 | 仄仄平平仄平仄 |

> 程序对这种情况**直接判为合律**，并在报告中标注「特拗句（已认可）」，
> 避免误报为出律。


## 六、半拗

定式「**仄仄平平仄**」，第三字作仄：

```
定式：仄 仄 平 平 仄
半拗：仄 仄 仄 平 仄
```

只拗不犯禁忌，**可以不救**。若要对句相救，则对句「平平仄仄平」第三字改平
成「平平平仄平」，称「半拗相救」。

七言「平平仄仄平平仄」第五字作仄，同理。


## 七、一三五不论的边界（速查表）

| 句式 | 五言可不论 | 七言可不论 | 需要当心 |
| --- | --- | --- | --- |
| 仄仄平平仄 | 第 1 字 | 第 1、3 字 | 第 3 字／第 5 字作仄 → 半拗（可接受） |
| 平平仄仄平 | 第 1 字 | 第 1、3 字 | **作仄即孤平**，须在第 3 字／第 5 字用平救回 |
| 平平平仄仄 | 第 1 字 | 第 1、3 字 | 第 3 字／第 5 字作仄 → 三仄尾（警告） |
| 仄仄仄平平 | 第 1 字 | 第 1、3 字 | 第 3 字／第 5 字作平 → **三平调（大忌）** |

> 括号中「第 3 字／第 5 字」前者指五言，后者指七言。


## 八、程序判定优先级

校验时按下列顺序处理每个字，先命中者为准：

1. **与定式完全一致** → 合律。
2. **不同之处落在「不论」位置** → 合律（从宽）。
3. **该字为多音字，另一种读音可满足定式** → 合律（标注「借读」）。
4. **整句符合特拗变体** → 合律（标注「特拗句」）。
5. **整句符合半拗** → 合律（标注「半拗」）。
6. **该句犯孤平但符合拗救式** → 合律（标注「孤平拗救」）。
7. **该句犯孤平 / 三平调** → **出律（大忌）**。
8. **该句犯三仄尾** → **警告（小病）**。
9. **其余不符** → **出律**。
