# 示例

用这些文件试跑校验器：

```bash
python main.py 示例/01-五言绝句-登鹳雀楼.txt
python main.py 示例/06-有毛病的诗-待改.txt
```

或者一次跑完：

```bash
python -m unittest discover -s tests -v
```

| `01-五言绝句-登鹳雀楼.txt` | 五言绝句 | 最标准的「仄起仄收」格式，四句全合律 |

| `06-有毛病的诗-待改.txt` | 五言绝句 | **故意写错**：三平调 + 出韵，看程序如何报错 |

## 自己写一首试试

把诗直接粘到命令行：

```bash
python main.py -t "你的诗句，每句五字或七字，句数为偶数。"
```

或者写进文件再跑：

```bash
python main.py 我的诗.txt
```

没有标点也没关系，程序会按 5 字或 7 字自动分句。

填词则要在标题里写明词牌：

```
《忆江南》
春去也，多谢洛城人。弱柳从风疑举袂，丛兰裛露似沾巾。独坐亦含颦。
```

或写成「词牌·题目」：

```
忆江南·春去也
...
```

支持的词牌见 `python main.py --list-cipai`。
